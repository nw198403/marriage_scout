# 婚活スカウト

結婚を考える会員が先にプロフィールを登録・公開し、複数の結婚相談所カウンセラーが得意分野・実績・星評価を掲げてスカウトに行く、逆求人型の「結婚相談所選び」プラットフォームです。

会員は届いた複数のスカウトを比較し、自分に最も合うカウンセラーを選んで入会・活動を始めます。お見合い・成婚そのものは各相談所（IBJ等）の既存の仕組みに委ね、本サービスは「自分に合うカウンセラーを選ぶ」入口に特化することで、既存の結婚相談所プラットフォームとは競合しない立ち位置を取っています。

G's Academy 卒業制作として、PHP + MySQLでログイン・データ管理機能を実装しています。

事業計画書は [docs/business_plan.pdf](docs/business_plan.pdf) を参照してください。

## コンセプト

- **逆求人型**：会員が先に登録・公開し、複数のカウンセラーがスカウトに行く構造（検索して探すのではなく、選ばれる・選ぶ）
- **透明性**：カウンセラーの得意分野・実績・星評価を可視化し、会員が比較して選べる
- **非対称な料金設計**：会員登録・利用は無料。カウンセラー側が契約成立時に紹介手数料（入会1件につき定額1万円）を支払う成果報酬型

## 主な機能

- 会員／カウンセラーの登録・ログイン（メール認証、パスワードはハッシュ化、セッション固定攻撃対策）
- 相談所（店番）と所属カウンセラーの分離、相談所単位での掲載審査（運営による承認・却下）
- 会員プロフィール登録（基本情報・希望条件・MBTIタイプの自己申告など）
- カウンセラープロフィール登録（得意分野・実績・料金・対応エリア・プロフィール写真・MBTIタイプなど）
- 会員検索・絞り込み（カウンセラー側）、スカウト送信
- スカウトの比較・初回面談の設定／辞退（会員側）
- 面談日程調整（カウンセラーが候補の時間帯を複数提示 → 会員が開始時刻を選んで提案 → カウンセラーが確定、の2段階フロー）、オンライン会議URL共有、カレンダー登録用.icsファイル出力
- スカウトごとのメッセージ機能
- 契約成立の申告・確認フロー（会員申告 → 運営がカウンセラー・相談所双方にメールで確認 → 運営が最終確定）、紹介手数料（入会1件につき定額1万円）の自動記録
- 契約成立後のレビュー・星評価（5項目）
- 会員・カウンセラー向けの進捗ステップバー、退会機能

本人確認書類・独身証明書・収入証明書は有効期限があるため、プラットフォーム上では預からず、契約時に各相談所が直接受け取る設計としています。

## 利用者の種類

| 種別 | できること |
| --- | --- |
| 会員 | プロフィール登録、スカウトの閲覧・比較、面談日程の調整、契約申告、レビュー投稿 |
| カウンセラー | プロフィール登録、会員検索、スカウト送信、面談日程の提示・確定、契約申告 |
| 相談所代表者 | 相談所情報（加盟連盟・加盟番号・加盟書類など）の管理、招待コードによる所属カウンセラーの追加 |
| 運営（管理者） | 相談所の掲載審査（承認・却下）、契約成立の最終確認 |

## 使用技術

| 項目 | 内容 |
| --- | --- |
| 言語・DB | PHP + MySQL（PDO、プリペアドステートメント） |
| ローカル開発環境 | XAMPP（Apache + PHP + MySQL） |
| 本番環境 | さくらインターネット（共有ホスティング） |
| デプロイ | FTPアプリ（Cyberduck / FileZilla等）でファイル一式をアップロード |
| セキュリティ | パスワードのハッシュ化（password_hash）、ログイン時のセッションID再発行、アップロードファイルの拡張子・サイズ制限 |

## セットアップ（ローカル）

1. 本リポジトリを `htdocs` 配下（XAMPP利用の場合）に配置する
2. `config.example.php` を `config.php` としてコピーする（`config.php` は `.gitignore` 対象）
3. MySQLに `marriage_scout` という名前でデータベースを作成する
4. `schema.sql` を流し込んでテーブルを作成する
   ```
   mysql -u root marriage_scout < schema.sql
   ```
   （phpMyAdminから `marriage_scout` データベースを選択し、「インポート」から `schema.sql` を指定する方法でも可）
5. XAMPPを起動し、`http://localhost/マリッジスカウトのフォルダ名/` にアクセスする

## ディレクトリ構成

```

├── index.php            トップページ
├── login.php / logout.php / register.php / verify.php   認証まわり
├── config.example.php   設定ファイルのテンプレート（config.phpの元）
├── schema.sql            DBの初期構築用SQL
├── migrate_*.sql          DBスキーマの差分更新用SQL
├── member/                会員向け画面
├── counselor/              カウンセラー向け画面
├── admin/                  運営（管理者）向け画面
├── includes/                共通処理（DB接続・認証・メール送信・マスタ定義など）
└── assets/                  CSS・画像
```

## 実装範囲について

本人確認書類等の真正性審査ロジック、紹介手数料の決済連携、MBTIの相性診断ロジックなどは、卒業制作のスコープ外としています（ファイルアップロード・データ記録・表示までを実装対象とし、審査・判定ロジックは持ちません）。
